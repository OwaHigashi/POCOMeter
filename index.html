        予測方法と検証結果

        曜日別の暫定予測は、直近14日中央値を、過去56日の曜日傾向で調整します。各日の値を同じ週の中央値と比べ、同じ曜日の観測が少ないほど調整幅を小さくします。その系列の実績が少ない場合は、同じ締め時間・ランク帯の曜日傾向を使います。

        暫定補正は、過去の休日・イベント予定と実績を同じ締め時間で照合して推定します。イベントの対象ランク、種類、重複時間、ランキングの有無、最終日、同時開催を使います。イベントの増減は直近14日の通常の開催状況を基準にしています。

        検証では、締めまでの24時間が始まる時点で確認済みだった情報を使い、中央値、曜日別予測、曜日・休日を使う正則化回帰、イベント回帰を比較します。予定と実績を後から照合した暫定補正の精度は、まだ検証できていません。

        休日の入力は、祝日・振替休日など、お盆（8月13〜16日を目安）、年末年始（12月29日〜1月3日）との重なりです。先の日付ではイベントが追加・変更されることがあります。予測日までの日数ごとの精度は検証中です。

        参考比較は13時締めのB1・A1の24件です。平均絶対割合誤差（MAPE）は中央値 8.06%、イベント補正あり 8.60%、前週同曜日 11.27%でした。

        非公式の予測です。最新のメーターはPocochaアプリで確認できます。 JSON API ／ CSVダウンロード
